# Apps

Three separate frontends, one monorepo, sharing `packages/shared` (types + mock data)
and — for the two React Native apps — `packages/ui` (design tokens).

| App | Status | Stack |
| --- | --- | --- |
| `business-app` | **In progress** (Phase 1) | Expo / React Native + NativeWind |
| `customer-app` | Not started (Phase 2) | Expo / React Native + NativeWind |
| `admin-web` | Not started (Phase 3) | Next.js + React + Tailwind |

See [`docs/10-frontend-phase-plan.md`](../docs/10-frontend-phase-plan.md) for the screen
inventory and build order within each phase.
